# Критичные улучшения безопасности и надёжности

## ✅ Реализованные улучшения

### 1. Конфигурация и константы (`config.py`)

**Проблема**: Магические значения и пути разбросаны по коду
**Решение**: Централизованный файл конфигурации

- ✅ Все настройки в одном месте
- ✅ Переменные окружения из `.env`
- ✅ Константы для кнопок, текстов, лимитов

**Использование**:
```python

```

### 2. Кастомные исключения (`exceptions.py`)

**Проблема**: Generic `Exception` затрудняет отладку и обработку ошибок
**Решение**: Специфичные классы исключений

- ✅ `TemplateNotFoundError` - шаблон не найден
- ✅ `PDFConversionError` - ошибка конвертации
- ✅ `LibreOfficeNotFoundError` - LibreOffice не установлен
- ✅ `PDFConversionTimeoutError` - таймаут конвертации
- ✅ `ValidationError` - ошибка валидации данных
- ✅ `RateLimitExceededError` - превышен лимит запросов
- ✅ `AccessDeniedError` - доступ запрещён

**Использование**:
```python
try:
    pdf_path = await generate_contract(data)
except TemplateNotFoundError:
    await message.answer("Шаблон не найден")
except PDFConversionError:
    await message.answer("Ошибка создания PDF")
```

---

### 3. Валидация данных (`validators.py`)

**Проблема**: Отсутствует проверка формата данных
**Решение**: Комплексная валидация всех полей

Реализованные валидаторы:
- ✅ `validate_phone()` - телефон (+7, 8, международный)
- ✅ `validate_email()` - email (RFC 5322)
- ✅ `validate_inn()` - ИНН (10 или 12 цифр)
- ✅ `validate_passport_series()` - серия паспорта (4 цифры)
- ✅ `validate_passport_number()` - номер паспорта (6 цифр)
- ✅ `validate_date()` - дата в формате ДД.ММ.ГГГГ
- ✅ `validate_birth_date()` - дата рождения (возраст 18-120)
- ✅ `validate_bik()` - БИК банка (9 цифр)
- ✅ `validate_bank_account()` - банковский счёт (20 цифр)
- ✅ `validate_amount()` - сумма договора
- ✅ `sanitize_text()` - защита от Jinja2 инъекций

**Использование**:
```python
from validators import validate_field, ValidationError

try:
    validate_field("client_phone", "+79171234567")
except ValidationError as e:
    print(e.message)  # "Неверный формат телефона"
```

**Примеры валидных значений**:
```python
# Телефон
"+7-917-123-45-67"  # ✅
"+79171234567"       # ✅
"89171234567"        # ✅

# Email
"user@example.com"   # ✅

# ИНН
"1234567890"         # ✅ (10 цифр - ЮЛ/ИП)
"123456789012"       # ✅ (12 цифр - физлицо)

# Дата
"15.03.1990"         # ✅
```

### 5. Аутентификация и Rate Limiting (`middleware.py`)

**Проблема**: Нет контроля доступа, возможен спам
**Решение**: Middleware для безопасности

#### `AuthMiddleware`
- ✅ Белый список пользователей (`ALLOWED_USER_IDS`)
- ✅ Логирование попыток доступа
- ✅ Блокировка неавторизованных пользователей

#### `RateLimitMiddleware`
- ✅ Лимит 10 договоров в час (настраивается)
- ✅ Лимит 50 договоров в день (настраивается)
- ✅ Автоочистка истории действий
- ✅ Раздельные счётчики для каждого пользователя

**Логирование**:
```
[WARNING] Попытка доступа от неавторизованного пользователя: 123456789 (@username)
[WARNING] Пользователь 987654321 превысил лимит: 10/10 за час
```

## 🔧 Настройка

### 1. Обновите `.env` файл

```bash
# Скопируйте пример
cp .env.example .env

# Отредактируйте .env
nano .env
```

Добавьте:
```env
# Ваш токен от @BotFather
BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11

# ID пользователей с доступом (необязательно)
ALLOWED_USER_IDS=123456789,987654321

# Лимиты (необязательно, есть defaults)
MAX_CONTRACTS_PER_HOUR=10
MAX_CONTRACTS_PER_DAY=50
```

### 2. Узнайте свой Telegram User ID

Способ 1 - через бота:
1. Напишите [@userinfobot](https://t.me/userinfobot)
2. Скопируйте ID

Способ 2 - через JSON:
1. Напишите [@getidsbot](https://t.me/getidsbot)
2. Получите свой ID

### 3. Настройте аутентификацию

**Вариант А: Открытый доступ** (не рекомендуется)
```env

```

**Вариант Б: Только вы**
```env
ALLOWED_USER_IDS=123456789
```

**Вариант В: Вы + коллеги**
```env
ALLOWED_USER_IDS=123456789,987654321,555666777
```

### 4. Примените патч к handlers.py (опционально)

Для полной интеграции валидации:


Или используйте handlers.py как есть (базовая валидация работает).

## 🆘 Проблемы и решения

### Проблема: `ModuleNotFoundError: No module named 'config'`

**Решение**:
```bash
# Убедитесь, что все файлы в одной директории
ls -la *.py

# Должны быть:
# config.py
# exceptions.py
# validators.py
# middleware.py
# handlers.py
# main.py
```

### Проблема: `BOT_TOKEN не установлен`

**Решение**:
```bash
# Проверьте .env файл
cat .env

# Должно быть:
BOT_TOKEN=ваш_реальный_токен

# НЕ ДОЛЖНО БЫТЬ:
BOT_TOKEN=your_bot_token_here  # ← это пример!
```

### Проблема: "Доступ запрещён" даже для вас

**Решение**:
```bash
# Узнайте свой ID
# Напишите @userinfobot в Telegram

# Добавьте в .env
ALLOWED_USER_IDS=ваш_реальный_id

# Перезапустите бота
```

### Проблема: Валидация не работает

**Решение**:
Примените патч из `handlers_patch.py` или убедитесь, что импортировали:
```python
from validators import validate_field, ValidationError
```
